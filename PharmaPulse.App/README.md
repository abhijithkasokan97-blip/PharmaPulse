# 💊 PharmaPlus - Pharmacy Management System

**PharmaPlus** is a web-based pharmacy inventory and sales management system built with Angular and Angular Material. It allows pharmacy managers and staff to efficiently monitor medicine stocks, track upcoming expiration dates, add new inventory items, and view complete historical sales records.

---

## ✨ Features

- 📦 **Medicine Inventory Management**: View, filter, and track available medicine stock details (Name, Brand, Price, Quantity, Expiry Date).
- 🚨 **Visual Stock & Expiry Alerts**:
  - Highlights low-stock items in **Red**.
  - Highlights items approaching expiration in **Yellow**.
- 🔍 **Real-Time Search**: Filter the inventory list instantly by medicine name or brand using Reactive Forms.
- ➕ **Add New Medicine Modal**: Interactive Angular Material Dialog form to quickly append new stock items with full validation.
- 📜 **Sales History Tracking**: View detailed transactional records including sales timestamp, medicine name, unit quantity sold, unit price, and total revenue calculation.
- 🎨 **Modern UI**: Styled with modern design principles using Angular Material components.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Framework**: [Angular](https://angular.dev/) (v16+)
- **UI Component Library**: [Angular Material](https://material.angular.io/)
- **State & Form Handling**: RxJS & Angular Reactive Forms
- **Styling**: SCSS / CSS3
